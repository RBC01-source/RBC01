# SST Pymes Perú: maqueta

Maqueta clicable del recorrido de un cliente de SST Pymes Perú: oferta y planes, alta, calendario anual, aviso por correo, panel del responsable, resumen semanal con semáforo y cartera interna.

Todo usa datos de ejemplo. No envía correos, no cobra y no guarda nada.

Para verla en línea: Settings, Pages, rama `main`, carpeta `/ (root)`.
